# Ravena Pescaria RPG V6.2.3 — Perfil e Pescador

- Novo botão 👤 de perfil no mobile.
- Nome editável (3 a 18 caracteres), salvo localmente por conta de demonstração.
- Exibe capturas, lendários, recorde, moedas, nível demonstrativo e skin equipada.
- O nome é somente visual: identificadores internos e progresso não são renomeados.
- Modelo masculino com rosto, torso e braços menos quadrados. Modelo feminino preservado.
- Sistemas de pesca, mercado, skins e controles mantidos.

**Limites:** sem autenticação online; XP é uma representação local derivada de capturas. Testar visual e toques em Android.
